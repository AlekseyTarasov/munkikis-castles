Munkiki’s Castles — 3D-головоломка з Nokia 3410 (2003), одна з перших 3D-ігор для телефонів.

Усі 30 рівнів, оригінальна графіка 96×65, звуки, палітри Nokia 3410 та чорно-біла.

Рушій написаний з нуля, файлів Nokia в ньому немає — гру він бере з оригінального jar (збірки 1.06/1.08). Заводські збірки збережено на archive.org (дякую Tim A.):
https://archive.org/details/munkikis-castles-15-builds-v1.06-v1.08

Підходить будь-яка збірка. В KKMFinal__OBF_packe є офіційний український переклад Nokia — з нею меню й навчання будуть «рідними».

Як запустити:

Поклади munkiki.bin і jar-файл гри (наприклад, KKMFinal__OBF_packe.jar) у /sd/munkiki/
Відкрий munkiki.bin у KeiraOS
